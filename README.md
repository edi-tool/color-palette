# 配色さん

印象語から方向性の違う配色を見比べ、AIに渡す配色指示文までコピーできるブラウザツールです。

🔗 https://edi-tool.github.io/color-palette/

試作版（v0.1.0）です。語彙・面積比・距離の閾値は評価前の目安で、今後調整します。

## 使い方

1. 「どんな印象にしたいですか？」で印象語を1〜3つ選びます。24案が並びます。
2. 気に入った案をタップ（PCは右側、スマホは下から開くシート）。色を編集・ロックできます。
3. 「AIに渡す配色指示をコピー」で、役割・用途・面積比・守ってほしいことを含む指示文をコピーします。

## データの扱い

- 入力・選択した色は **ブラウザ内で処理し、外部へ送信しません**。ログイン・分析・広告はありません。
- 状態はURLの `#` 以降にだけ保存されます（サーバーには送られません）。
- 外部から読み込むもの: なし（ライブラリ未使用）。

## 判定基準・計算根拠と出典

- 色演算: OKLab/OKLCH（Björn Ottosson の公開定義 https://bottosson.github.io/posts/oklab/）を自前実装。色域外はsRGBへ彩度低減でマッピング。
- コントラスト: WCAG 2.x の相対輝度。通常文字は 4.5:1 を目安に警告します。
- 語彙辞書（`src/vocab.json`）: 独自作成の初期値で、レビュー・評価前です。印象と色の対応は目安であり、主観的な近似です。
- 生成方法: 温度×彩度×調和の層別サンプリング、印象適合度の下限、最遠点選抜（`DESIGN.md` 参照）。

## 制限事項

- **CMYK数値は提供していません。** 印刷向けモードは高彩度を避ける参考表示のみです（ICC変換は今後）。
- 画像生成AIでの色再現、印刷結果は保証しません。
- 語彙は30語。未知語は近い候補を示すだけで、自動解釈はしません。

## 開発

ビルド工程はありません。

```bash
python -m http.server 8000   # プレビュー
npm test                     # テスト（Node.js 22 以上、依存なし）
npm run check                # HTML の静的チェック
```

E2E（Playwright）は `tests/e2e/` に分離しています（本体は依存なしのまま）。システムの Chrome を使います。

```bash
cd tests/e2e && npm ci && npx playwright test
```
