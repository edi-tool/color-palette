生成案の評価（開発用・公開しない）

今の生成エンジンが出す案に、良い／微妙／悪いを付けてください。悪い・微妙には、当てはまる理由を選ぶと集計できます（複数可）。

「★お手本」は、シード配色の候補にしたい案に付けます。各語の上の欄には、24案全体の感想（幅が狭い、印象とずれる等）を書けます。

評価はこのブラウザに自動で保存されます。終わったら「結果を保存」で JSON を書き出し、docs/eval/results/ に置いてください。案は固定の seed で作るので、毎回同じ案が出ます。

途中経過は約1分ごとに「控え」として別に残ります（最大30件）。消えたり間違えたりしたときは、右上の「控えから戻す」で選んでください。念のため、区切りのよいところで「結果を保存」もしておくと確実です。
