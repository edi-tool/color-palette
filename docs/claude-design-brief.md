## 依頼の目的

「配色さん」は、日本語の印象語（明るい・知的など）から方向性の違う配色を24案ずつ見比べ、好みの案を調整し、AIに渡す配色指示文をコピーできるブラウザツールです。
動作するMVPはできています。**見た目・情報設計・用途別プレビュー・OGP画像**の品質を上げるため、デザイン面を依頼します。

## 依頼する範囲

1. **デザイン指針**（文章、A4で2〜3枚程度）
   - 色・余白・文字サイズ・角丸・影の方針（ライト／ダーク両対応）
   - 配色カードの見せ方（5色の面積差、系統ラベル、選択中の表現）
   - スマホ（390px基準）の「下から開く詳細シート」と、PC（1024〜1440px）の横並び詳細欄の使い分け
   - 状態の表現: 選択中・ロック中・エラー・コピー成功・印刷向け注意
2. **画面案**（390px と 1440px、ライト／ダーク）
   - 初期（印象語選択）／24案の一覧／詳細（編集・ロック・コピー）／深掘り表示中／印刷向けモードの注意／不正HEXのエラー／コピー失敗時のフォールバック欄
3. **用途別プレビューの見本**（5種）: 一般／書籍カバー／チラシ・ポスター／教材・学級通信／Web・SNS
   - 実際の成果物を保証する表現にしない。「見本」であることが分かること
4. **OGP画像**（1200×630、PNG）: 「配色さん」＋一文の価値。edi-tool 共通の雰囲気に合わせる

## 守ってほしい制約

- **実装は静的HTML/CSS/素の ES Modules**。フレームワーク、外部フォント、CDN、画像の外部読み込みは使わない。
- edi-tool 共通トークンに合わせる（既存ツールと並んだときに統一感があること）:
  背景 `#f8f6f2` / アクセント `#f28c06` / アクセント濃 `#d97a00` / アクセント淡 `#fff8f0` / 文字用アクセント `#b35f00` / 文字 `#0f0f0f` / 枠線 `#e0e0e0`。
  現行の実装値は `styles.css` の `:root` を参照。
- アクセシビリティ（受け入れ条件）:
  - タップ領域 44×44 CSS px 以上
  - 文字と背景のコントラスト比 4.5:1 以上（通常文字）。ダークモードも同様
  - 状態を**色だけで区別しない**（選択・ロック・エラーは形状／文字／アイコンを併用）
  - 文字200%拡大で横スクロールや欠けが出ない（320〜1440px）
  - キーボード操作とフォーカスの可視化
- 画面の主役は**配色候補**。UIの色が候補の見え方を邪魔しない（UIは中立寄りに）。
- 主操作は「AIに渡す配色指示をコピー」。詳細欄の目立つ位置に置き、スクロールで埋もれない。
- 日本語UI。文言は平易に（専門用語を必須にしない）。
- 書いてはいけない表現: 「印刷色を保証」「画像生成AIで同じ色になる」「CMYK対応」（CMYK数値は未提供のため）。
- 機密・未公開原稿・個人情報は成果物に入れない。サンプル文は架空のものにする。

## 成果物の形式と受け渡し

- 指針は Markdown（`docs/design-guidelines.md` として置ける形）。
- 画面案は画像（PNG）またはHTML。実装に使えるCSS変数・主要コンポーネントのHTML/CSS断片があると助かります。
- 既存のクラス名・`data-*` 属性・`id` を変える場合は、対応表を付けてください（E2Eが依存しています）。
- 取り込みと回帰確認（`npm test`、`npm run check`、E2E）は Claude Code 側で行います。
